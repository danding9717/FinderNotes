- 保存按钮和 Command-S 使用同一手动入口，捕获会话、文件身份、自有属性原始字节基线、草稿修订和完整 UTF-8 字节。缺失属性显式保存空正文时创建零字节属性；主动清空已存在的笔记也保存零字节属性。保存前核对身份和自有属性，写后完整回读比较并再次核对身份；只有成功才显示已保存。无关 xattr 或 mtime/ctime 变化不当作笔记正文冲突。
- 已知外部正文改动、文件消失、同名或父目录替换时停止覆盖并留住草稿。写后回读或身份复核失败时报告“写入结果未能确认”，不声称旧文件未变。旧异步结果只作用于原会话和对应修订，不回填编辑器或清除撤销、选区；较新草稿继续显示未保存。保存和导出期间可继续编辑、复制，暂缓再次保存和切换、关闭、退出；输入法组合态先完成输入再操作。
- Markdown 导出冻结操作开始时的内存正文，默认 `完整原文件名.note.md`，只写原始 UTF-8，无 BOM、标题和元数据。导出不改变笔记保存状态。目标目录中独占创建临时文件，写入、同步、完整回读后用 `RENAME_EXCL` 发布；拒绝素材自身、链接目录、已有目标及抢占，不降级为覆盖。保存失败或源文件消失后仍可从草稿复制、导出。

**明确的并发边界：** macOS 的 `XATTR_CREATE` / `XATTR_REPLACE` 仅按属性存在与否约束写入，不能以旧正文原始字节为条件原子更新。最后一次检查与 `fsetxattr` 之间仍有竞态；持有文件描述符也可能写到刚被移走的原对象。写后回读不证明面对任意并发者的安全性。验收中请结束编辑后再整理、移动素材；遇到结果未确认先复制或导出草稿，再重新打开核对，不盲目重试覆盖。
